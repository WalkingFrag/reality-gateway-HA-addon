КОНФИГУРАЦИЯ

Выходные AmneziaWG

Экспортируйте полный текстовый профиль AmneziaWG 3.1 и вставьте блоки [Interface] и [Peer]. Каждый сервер проверяется отдельно; первым выбирается выход с наивысшим приоритетом.

Профили из настроек Home Assistant сохраняются. Добавленные здесь выходы идут после них и перед VLESS.

Приватные ключи хранятся только в данных аддона. В ответе панели они не передаются.

КОНФИГУРАЦИЯ

Дополнительные VLESS

Вставьте ссылку vless:// с параметрами Reality. Имя после # появится в списке туннелей.

Новые подключения проверяются отдельно и выбираются по порядку добавления после AWG. Основной VLESS из настроек аддона остаётся последним резервом.

Ссылка содержит ключи доступа. Она хранится только в данных аддона и не возвращается в панель.
